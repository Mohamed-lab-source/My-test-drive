# Khroga

Plan real outings in Cairo, Giza and Alexandria, with real places and your friends.
**Runs entirely on free services.** No billing anywhere.

- **Plan**: describe the group, vibe and budget → a multi-stop plan built only from real places.
- **Explore**: browse and search real places, with hours, phone, website and directions.
- **Groups**: invite friends with a code, RSVP, chat, and see who pays.
- **Friends**: usernames, search, and QR codes.

**Setting it up?** Follow [SETUP.md](SETUP.md) (browser only, about 10 minutes).

Tech: Flutter + Riverpod + go_router; Firebase Spark plan (Auth + Firestore, no Cloud
Functions); Gemini free tier called from the app; OpenStreetMap places bundled at build
time; Open-Meteo weather. Place data © OpenStreetMap contributors (ODbL).
