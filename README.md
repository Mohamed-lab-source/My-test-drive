## Jarvis — personal AI secretary (native Android app)

A real installable Android APK: voice + text chat, morning briefings, real
Google Calendar and Gmail, commute checks, reminders that fire as genuine
OS notifications even when the app is closed, and real phone control —
calling/texting contacts by name, alarms, timers, and flashlight. Brain:
Groq — free, no credit card, ever. Built and packaged automatically by
GitHub Actions — no Android tooling needed on your end.

See [`android-app/README.md`](android-app/README.md) for setup (download
the APK, install it, add your free Groq API key — ~10 minutes).
