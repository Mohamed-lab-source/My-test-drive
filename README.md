# Khroga

Plan real outings in Cairo, Giza and Alexandria — with real places and your friends.

- **Plan**: describe the group, vibe and budget → a multi-stop plan built only from real places.
- **Explore**: browse and search real places, with photos, hours and directions.
- **Groups**: invite friends with a code, RSVP, chat, and see who pays.
- **Friends**: usernames, search, and QR codes.

**Setting it up?** Follow [SETUP.md](SETUP.md) step by step.

Tech: Flutter + Riverpod + go_router, Firebase (Auth, Firestore, Cloud Functions, Messaging),
Google Gemini for planning, Google Places API (New) for real place data, Open-Meteo for weather.
